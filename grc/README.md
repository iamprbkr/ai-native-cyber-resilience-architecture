# Governance, Risk & Compliance (GRC)

GRC artifacts for the AI-native cyber resilience architecture. These documents align with NIST CSF 2.0, ISO 27001:2022, and Zero Trust principles (NIST SP 800-207).

## Contents

| File | Purpose |
|------|---------|
| `risk-register.yaml` | Risk register with inherent/residual scoring |
| `control-matrix.yaml` | Security controls mapped to frameworks |
| `policy-framework.md` | Policy framework and hierarchy |
| `compliance-mapping.md` | Cross-walk between NIST CSF, ISO 27001, and MITRE ATT&CK |
| `business-continuity.md` | BCP strategy and RTO/RPO targets |
| `disaster-recovery.md` | DR plan for the platform itself |
| `roi-analysis.md` | ROI model, TCO comparison, payback period |
| `metrics-kpis.md` | KPI tree and measurement framework |
